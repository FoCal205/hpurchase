# InstaPay — Hire Purchase Tracker

A complete desktop application for managing hire purchase installment payments.
Built for retail businesses where clients pay for items in daily contributions.

## Features
- Worker login system with individual dashboards
- Admin dashboard with full audit and analytics
- Client management with unique codes
- Payment recording and balance tracking
- Delivery confirmation and receipts
- Cloud folder backup (OneDrive, Google Drive, Dropbox)
- Multi-branch support
- Analytics charts
- White-label — fully configurable branding

## Default Login
- Admin password: `admin123` (change after first login in Settings)
